# Agent Core Rules

Use these rules when context is tight. They are the shortest stable operating law for this repo.

1. Machine truth over prose.
2. Fail closed over convenience.
3. Correctness over speed.
4. Deterministic substrate over clever orchestration.
5. One dominant correctness question per atom.
6. If the task proves more than one thing, split it.
7. State ordering and field requirements explicitly.
8. Only claim what you actually verified.
9. Use human intervention when the residue is narrower than another full agent loop.
10. Do not merge through failing post-merge checks.
