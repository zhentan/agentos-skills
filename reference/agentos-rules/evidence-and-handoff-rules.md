# Evidence And Handoff Rules

Date: 2026-04-01

Use these rules for any task that leaves an artifact or optional handoff summary.

1. Structured evidence outranks prose.
2. Runtime-owned truth outranks artifact prose when they disagree.
3. `completed` is an agent fact; `merged` is a kernel fact.
4. Required artifact paths must be explicit in the task contract.
5. Machine-captured validation records are the authoritative source for command results.
6. Handoffs are summaries, not evidence ledgers.
7. Do not claim full-suite coverage unless the full suite was actually run.
8. Merge eligibility should depend on machine records and routing gates, not prose restatements.
